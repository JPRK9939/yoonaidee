# 🏠 อยู่ไหนดี — สำรวจ & เปรียบเทียบที่พัก กทม. และปริมณฑล

### 👉 เปิดใช้งาน: **https://jprk9939.github.io/yoonaidee/**

เว็บสำหรับหาคอนโด หอพัก อพาร์ตเมนต์ แมนชั่น และบ้านเช่า ทั่วกรุงเทพฯ และปริมณฑล
ดูบนแผนที่ 2D/3D แล้วตัดสินใจว่าที่ไหน "เหมาะจะไปอยู่" — ทั้งเรื่องราคา การเดินทาง น้ำท่วม ร้านค้ารอบ ๆ และบรรยากาศย่าน
ใช้ได้ทั้งบนคอมและมือถือ (มือถือเป็นเวอร์ชันลีน)

## ✨ ทำอะไรได้บ้าง
| | ฟีเจอร์ |
|---|---|
| 🗺️ | **แผนที่ 2D / 3D** สลับได้ + 4 สไตล์ (เรียบ / สีสัน / มืด / ดาวเทียม) · ซูมออกจุดจะรวมเป็นกลุ่ม ซูมเข้าเห็นทุกจุด |
| 🏢 | **ที่พักจริง ~49,000 แห่ง** (Overture Maps + OpenStreetMap) ค้นหาด้วยชื่อ/เขต/สถานี กรองตามประเภทและงบ |
| 💸 | ค่าเช่า / ราคาตั้ง / ราคาขาย / ผลตอบแทนค่าเช่า *(ราคาเป็นค่าประมาณจากทำเล — ยังไม่มีแหล่งราคาจริงฟรี)* |
| 📍 | **ปักหมุดที่ทำงานได้หลายจุด** (ค้นหาสถานที่ได้) → ลากเส้นทางจริง + เวลาเดินทางรถยนต์/รถไฟฟ้า ช่วงรถติด |
| 🌊 | **จำลองน้ำท่วม/น้ำขัง** ปรับระดับน้ำ-ปริมาณฝน ดูลำดับเขตที่ท่วมก่อน-หลัง และผลต่อการเดินทาง |
| 🚦 | สภาพจราจรตามช่วงเวลา · 🚇 เส้นรถไฟฟ้า BTS/MRT/ARL · 👥 ความหนาแน่นประชากร · ⛰️ ความสูง-ต่ำพื้นที่ |
| 🏪 | **ร้านค้า ~278,000 ร้าน / 7-Eleven ~5,400 สาขา** รอบที่พักในรัศมี 800 ม. |
| ⚖️ | **หน้าเปรียบเทียบ** (แท็บแยก) คะแนน % แต่ละด้าน กราฟเรดาร์ ข้อดี-ข้อเสีย ปรับน้ำหนักความสำคัญเองได้ |
| 🐈 | **เดินสำรวจย่านแบบแมวยักษ์** เมือง 3D จากอาคาร/ถนนจริง ป้ายชื่อที่พักและ 7-Eleven มินิแมพ · ตึกที่บังจะโปร่งใส |
| ⚙️ | ตั้งค่าคุณภาพ (ประหยัด / ปกติ / สวย) ให้เครื่องไม่หน่วง |
| 🔜 | เชียงใหม่ · ภูเก็ต · ขอนแก่น · ชลบุรี · หาดใหญ่ — *Coming soon* |

### 🐈 ปุ่มในโหมดแมว
`W A S D` เดิน · เมาส์ หมุนกล้อง (ล็อกไม่ได้ให้กดลาก) · `Shift` วิ่ง · `Space` กระโดด · ล้อเมาส์ ซูม/มุมสูง · `E` ดูข้อมูลที่พักใกล้ ๆ · `M` มินิแมพ · `Esc` ออก
มือถือ: จอยซ้ายเดิน · ลากจอหมุนกล้อง · ปุ่ม ℹ️ / วิ่ง / โดด

## 💻 รันในเครื่อง
```
node server.js
```
แล้วเปิด http://localhost:5173 (ไม่ต้อง `npm install` — ไลบรารีโหลดจาก CDN)

## 📦 ข้อมูล (ฟรีทั้งหมด)
| ไฟล์ | แหล่ง | อัปเดตด้วย |
|---|---|---|
| `data/places-overture.json` | Overture Maps — ที่พัก ~43,000 แห่ง | `node tools/fetch-overture.mjs` |
| `data/places.json` | OpenStreetMap — ที่พัก ~10,000 แห่ง | `node tools/fetch-places.js` |
| `data/shops.json` | Overture Maps — ร้านค้า/สะดวกซื้อ/7-Eleven | `node tools/fetch-shops.mjs` |
| `data/places-manual.json` | ที่พักที่เพิ่มเอง (มีราคาจริงได้) | แก้ไฟล์ตรง ๆ |
| ปุ่ม "เพิ่มเองบนแผนที่" | เก็บในเบราว์เซอร์ของผู้ใช้ | — |

- เครื่องมือดึงข้อมูลต้องใช้ `npm install` (DuckDB) ก่อน
- ไฟล์ `*.local.json` / `*.local.glb` ใช้เก็บข้อมูลส่วนตัวในเครื่อง ไม่ถูกอัปขึ้น GitHub
- ความสูงพื้นที่ จราจร และราคา เป็น**แบบจำลอง/ค่าประมาณ** — ใช้ประกอบการตัดสินใจ ไม่ใช่ข้อมูลทางการ
- `tools/fetch-google-places.js` (Google Places API) มีไว้แต่ไม่ได้ใช้ เพราะต้องผูกบัตร
